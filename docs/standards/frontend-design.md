# MarkSurvey 前端视觉与交互规范

状态：生效
更新时间：2026-10-20
适用范围：`frontend/`

通用原则：禁止任何多余的解释性、防御性文字说明。

## 0. 共享设计令牌

### 颜色

| 用途 | Token | 色值 |
| --- | --- | --- |
| 页面背景 | `--color-bg` | `#F5F7FB` |
| 内容表面 | `--color-surface` | `#FFFFFF` |
| 主文字 | `--color-text` | `#172033` |
| 次级文字 | `--color-muted` | `#667085` |
| 边框 | `--color-border` | `rgba(23, 32, 51, 0.10)` |
| 主品牌蓝 | `--brand-primary` | `#2563EB` |
| 品牌蓝悬停 | `--brand-primary-hover` | `#1D4ED8` |
| 品牌橙 | `--brand-accent` | `#F97316` |
| 辅助青 | `--terracotta` | `#14B8A6` |
| 成功 | `--color-success` | `#16A34A` |
| 警告 | `--color-warning` | `#D97706` |
| 危险 | `--color-danger` | `#DC2626` |

配色规则：

- 蓝色负责主操作、链接、选中态和 AI/信息入口。
- 橙色只用于品牌点缀和局部强调，不作为全局主按钮色。
- 成功、警告、危险色只用于表达状态。
- 白色和浅灰应占页面主要面积。
- 单个页面最多使用一个主要模块强调色。
- 禁止随意新增品牌色和硬编码无关色值。

### 字体

- 字体栈：`PingFang SC`, `Microsoft YaHei`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, sans-serif。
- 登录页可使用 38–74px 的品牌大标题。
- 工作台主标题约 20px。
- Section 标题 16–18px。
- 正文、表格和表单正文 14px。
- Kicker 和辅助标签 12px。
- 中文正文行高 1.5–1.7。
- 工作区紧凑内容行高 1.2–1.45。

### 间距、圆角与控件

- 间距以 4px 为基准。
- 常用间距：8、12、16、20、24、32px。
- 卡片和表单内部间距：16–20px。
- 表格单元格内边距：10–12px。
- 常规圆角：8px。
- 小控件圆角：6px。
- 登录页使用整页布局，不使用外层卡片，不设置容器圆角或投影。
- 工作台圆角不超过 8px。
- 常规控件高度：40px。
- 小尺寸控件：34px。
- 大尺寸控件：46px。
- 移动端点击目标不小于 44px。
- 工作台阴影保持极弱或无阴影。
- 动效控制在 150–300ms。
- 尊重 `prefers-reduced-motion`。
- 禁止导致布局抖动的 hover 缩放和位移动画。

## 一、登录页规范

### 1.1 定位

- 登录页是品牌入口和认证工作区，需要兼顾品牌感、可信赖感和稳定的表单体验。
- 视觉可以比工作台更有品牌感，但不得影响登录、注册、找回密码和 OAuth 绑定流程。
- 统一使用 Ant Design 表单和反馈组件，不自绘表单体系。

### 1.2 布局

- 桌面端采用双栏布局：左侧品牌介绍区，右侧认证工作区。
- 推荐比例约 60/40，右侧认证区最小宽度约 420px。
- 页面锁定为单一视口：认证页使用 `height: 100dvh` 与 `overflow: hidden`，禁止页面级纵向和横向滚动。
- 左右区域垂直居中，认证工作区保持稳定宽度。
- 移动端默认降为单列：品牌摘要在上，认证工作区紧随其后；高度不超过 760px 时隐藏移动品牌摘要，高度不超过 620px 时启用紧凑间距。
- 登录、注册、找回密码、OAuth 补绑邮箱复用同一认证工作区心智，不分别设计成不同页面风格。
- OAuth 首登回调使用简洁弹层，不设计成步骤向导或多层信息卡。

### 1.3 视觉

- 背景使用白色渐变，叠加低透明度蓝色和橙色径向光晕。
- 主标题使用深墨色，不使用大面积高饱和渐变文字。
- 品牌介绍区可以包含一句主标题、简短说明和能力摘要卡片。
- 认证工作区铺满页面高度，以细边框或轻背景与品牌区衔接；不得使用浮动卡片、圆角容器和投影。
- 表单控件圆角约 10px。
- 登录主按钮圆角约 11px，高度不低于 38px。
- OAuth 图标按钮为圆形，尺寸约 44px。
- 橙色可用于品牌徽标、标签和少量强调，不用于替换主登录按钮的蓝色。
- 禁止使用大面积装饰插画和与认证无关的营销内容。

### 1.4 表单与交互

- 模式切换使用 Ant Design `Tabs`，不用两个普通按钮模拟 Tabs。
- 表单使用 `Form`、`Form.Item`、`Input`、`Input.Password`、`Checkbox` 和 `Button`。
- 邮箱验证码输入和发送按钮使用 `Space.Compact`。
- 滑块验证统一使用 Ant Design `Modal` 承载：密码登录提交后弹出，邮箱验证码发送前弹出；验证通过后关闭并继续当前流程。
- 字段错误优先显示在 `Form.Item` 层级。
- 顶部 `Alert` 只承载接口失败、验证码发送结果和流程说明。
- 用户协议和隐私政策使用 `Modal`，正文内部滚动。
- 登录、注册和找回密码的提交按钮必须有 loading 状态。
- 注册成功后需要明确提示 pending 用户后续进入 onboarding。
- 桌面端注册表单可以使用两列布局；移动端非成对字段保持单列，用户名/账号与密码/确认密码两组成对字段可在窄屏保持双列，以维持单一视口内完整显示。
- 移动端邮箱输入和验证码按钮应上下排列，避免拥挤。
- 任何流程不得在 320px 宽度产生横向滚动。
- 移动端所有触控目标不小于 44px。

### 1.5 登录页禁止项

- 禁止自绘按钮、输入框、弹窗和遮罩。
- 禁止把登录、注册、找回密码做成完全不同的视觉体系。
- 禁止把认证流程放入居中浮动卡片，或重复叠加容器与浮层。
- 禁止使用会导致布局跳动的 hover 缩放。
- 禁止在移动端把非成对字段排成多列。
- 禁止在 320px 宽度出现横向滚动。
- 禁止使用与品牌无关的装饰性背景图。

## 二、工作台规范

### 2.1 定位

- 工作台是面向重复性生产任务的工具型界面，优先保证稳定、清晰、高信息密度和可扫描性。
- 不使用营销式 Hero、大面积渐变、玻璃质感和装饰插画。
- 页面视觉层级通过布局、边框、字号、留白和局部语义色建立。
- 统一复用 Ant Design 和项目现有工作台组件。

### 2.2 AppShell 布局

- 顶部导航固定，桌面高度 60px，移动端 56px。
- 顶栏使用白色或半透明白色背景，配细边框和轻阴影。
- 工作台侧边栏固定，展开宽度 232px，收起宽度 72px。
- 面包屑高度约 42px。
- 页面标题栏固定高度 54px，白色背景。
- 页面标题字号约 20px，kicker 约 12px。
- 页面标题左侧放标题，右侧放操作。
- 页面标题默认不展示大段副标题，说明放入 Help、Tooltip 或空态。
- 工作台使用固定视口：导航、侧栏、面包屑、页头和筛选栏固定。
- 内容区高度通过 `100dvh` 减去顶部偏移计算。
- 表格、表单和长内容必须在内部滚动。
- 工作台核心操作不能依赖浏览器页面自然滚动。
- 侧栏被收起时，页头和内容区同步扩展，不出现空白断层。

### 2.3 页面骨架

列表页统一采用以下顺序：

1. 固定页面标题栏
2. 统计摘要，按页面需要保留
3. 单行搜索筛选栏
4. 表格或卡片主体

约束：

- 页头、摘要和筛选栏保持紧凑，不插入装饰性大标题。
- 统计摘要按需展示，不得为了凑满首屏强行增加卡片。
- 筛选栏默认保持单行。
- 超过 2–3 个低频筛选条件时，放入高级筛选 Drawer。
- 主体区域必须填满筛选栏到视口底部的剩余空间。
- 页面加载、空态和筛选变化不得造成明显位置跳动。
- 列表页优先使用表格，卡片视图只作为辅助扫描视图。

### 2.4 工作台模块色

| 模块 | 主色 | 浅色底 |
| --- | --- | --- |
| 工作台 / 数据生产 | `#2563EB` | `#EFF6FF` |
| 账号 / 人员管理 | `#16A34A` | `#F0FDF4` |
| 数据集 | `#0891B2` | `#ECFEFF` |
| 模板搭建 | `#7C3AED` | `#F5F3FF` |
| 任务发布 | `#EA580C` | `#FFF7ED` |
| 标注 | `#D97706` | `#FFFBEB` |
| 审核质检 | `#B45309` | `#FFF7ED` |
| 企业治理 | `#0F766E` | `#F0FDFA` |

模块色使用规则：

- 模块色只用于 section 标题、表头、面板顶部色带、Tabs 和局部图标。
- 不铺满页面背景。
- 不替换成功、警告和危险等语义色。
- AI 预审使用蓝色表达信息和辅助判断。
- 人工打回、风险和异常使用暖橙或红色。
- 页头统一使用白色，不按模块整块换色。

### 2.5 工作台组件

#### Button

- 主操作使用蓝色 primary。
- 危险操作使用 danger。
- 低频操作使用 text 或 default。
- 图标按钮必须提供 Tooltip。
- 图标按钮尺寸约 34–40px。
- 操作区按钮高度约 34–40px。

#### Form / Input / Select

- 使用 Ant Design `Form`、`Input`、`Select`、`DatePicker` 和 `InputNumber`。
- 每个字段必须有清晰 label。
- 控件高度默认 40px，圆角 8px。
- 字段错误显示在 `Form.Item` 层级。
- 筛选变化应支持防抖，避免频繁请求。
- 下拉展开不能造成页面滚动条抖动。

#### Card

- 只用于指标、列表项和表单分组。
- 工作台卡片圆角不超过 8px。
- 优先使用浅边框和白底，不堆叠阴影。
- 不把每个 section 都做成浮卡。
- 指标优先做成紧凑状态条，不做大面积卡片墙。

#### Tabs

- 用于同级视图切换。
- 选中态使用蓝色。
- 移动端 Tabs 可横向滚动，但不得撑出页面。
- 切换 Tabs 不应重置无关筛选条件。

#### Tag

- 状态标签使用明确语义色。
- 成功绿色，警告橙色，危险红色，信息蓝色。
- 标签保持轻量，不作为页面主视觉。
- 同类状态在全站保持同一颜色。

#### Drawer

- 用于详情、审核、编辑和复杂配置。
- 桌面宽度 420–720px。
- 移动端不超过视口宽度。
- 标题和底部操作固定，正文内部滚动。
- 不把复杂工作台塞入 Drawer。

#### Modal

- 只用于确认、短表单和危险操作。
- 不承载复杂工作台和长流程。
- 移动端最大高度不超过视口，正文内部滚动。
- 危险操作必须说明不可逆影响。

### 2.6 表格规范

- 优先使用项目 `EnhancedTable` 或 Ant Design `Table`。
- 默认使用固定布局。
- 支持列宽拖拽和横向滚动兜底。
- 固定表格启用 sticky header。
- 表格主体内部滚动，页头、统计和筛选不随表格滚动。
- 分页固定在右下角。
- 分页启用快速跳转，按业务需要启用每页条数选择。
- 当前数据为空或少于一页时，仍保留稳定的分页区域。
- 长文本使用 `ellipsis` 或详情 Drawer。
- 长内部 ID 不作为主列，使用短编号或二级信息。
- 行操作最多保留 2–3 个高频动作，其余放入 `Dropdown`。
- 常规操作列宽度约 138px。
- 单动作操作列宽度约 92px。
- 危险操作使用 `Popconfirm` 或 `Modal.confirm`。
- 表格列宽、滚动条和操作列不得因加载或筛选发生明显抖动。

### 2.7 卡片列表

- 卡片最小宽度约 280–320px。
- 卡片结构：状态标签 → 标题和两行描述 → 3 项关键指标 → 底部标签与操作。
- 卡片视图必须复用表格的搜索、筛选、加载和空态。
- 卡片网格内部滚动，底部固定分页。
- 切换表格和卡片视图不得重置筛选语义，只重置分页。
- 卡片内容必须截断，不能因长标题撑出横向滚动。

### 2.8 反馈与加载

- 短时成功/失败提示使用顶部 `message`。
- 页面级首次加载使用 `Spin` 或 `WorkspaceLoading`。
- 表格刷新使用 `Table loading`。
- 按钮异步操作使用 `Button loading`。
- 权限不足、阻断说明和空数据使用页面内 `Alert` 或 `Empty`。
- 不使用裸文本“正在加载...”作为工作台加载态。
- 不使用自造 Toast、浮层和遮罩。
- 错误提示必须说明恢复动作。
- 自动保存状态必须可见但不干扰。
- 危险操作必须二次确认。

### 2.9 响应式与可访问性

- 桌面优先覆盖 1280px、1440px 和 1920px。
- 平板端侧边栏可收起为图标栏。
- 移动端从 320px 起必须可用。
- 任何按钮、标签和表格单元格不得出现文字溢出覆盖。
- 页面不得出现页面级横向滚动。
- 移动端触控目标不小于 44px。
- 移动端弹窗和抽屉使用 `100dvh` 约束。
- 所有图标按钮提供 Tooltip 或可访问名称。
- 保持清晰的键盘焦点态。
- 焦点环可使用 `rgba(37, 99, 235, 0.26)`。
- 动效控制在 150–300ms。
- 禁止会导致布局抖动的 hover 缩放和位移动画。

### 2.10 工作台禁止项

- 禁止使用营销式 Hero 和大面积装饰。
- 禁止使用大面积渐变和玻璃拟态。
- 禁止把所有 section 做成浮卡或卡片墙。
- 禁止自造按钮、表单、弹窗、Toast 和表格体系。
- 禁止把橙色作为全局主操作色。
- 禁止页面级纵向滚动承载核心工作台操作。
- 禁止在一个页面堆叠多组高饱和强调色。
- 禁止把长内部 ID 塞进主表格列。
- 禁止无 Tooltip 的纯图标关键操作。
- 禁止 320px 宽度出现横向滚动。
- 禁止无二次确认的危险操作。
- 禁止用裸文本展示加载状态。
