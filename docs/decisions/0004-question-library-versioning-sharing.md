# ADR-0004：题库根、不可变题目版本与独立复制分享

- 状态：Accepted
- 日期：2026-10-29

## 背景

问卷题目需要跨问卷复用、独立演进、分享和跨问卷统计，同时不能改变已发布问卷及历史答卷的解释。现有问卷 Schema 题目内嵌在不可变问卷版本中，没有稳定题目资产边界。

## 决策

- 新增独立 `question_library` 领域，使用稳定题目根和不可变题目版本。
- 题目根锁定题型；新增版本不得改变题型，需要改变题型时派生新题目根并记录来源。
- 恢复历史版本采用“复制内容生成新版本”，不移动最新版本指针。
- 问卷 Schema 增加可选 `library_ref`，绑定具体题目版本；问卷题目实例 ID 与题库身份分离。
- 关联题目内容只读；问卷内可独立调整必答和跳转规则。修改题干、选项或约束会自动解除关联。
- 分享链接作用于题目根，要求登录，可选截止时间并可撤销；令牌只存哈希。
- 接收方每次导入都创建独立题目根 v1，保留来源但不自动同步后续版本。
- 问卷发布时写入题目使用记录，跨问卷统计依据使用记录和已提交答卷计算。
- 归档替代硬删除；归档题目不能新链接入或分享，但历史版本、使用记录和统计保留。

## 后果

- 题目内容和分享链接可独立于问卷演进，已发布问卷保持稳定。
- 同一题目需求变化可能产生多份独立副本，跨问卷统计只聚合题目根明确关联的答卷。
- 问卷发布需要额外校验和写入使用记录，跨问卷统计需要聚合多个问卷版本。
- 现有问卷不做隐式回填，只有显式保存并关联后的发布版本进入新统计体系。
