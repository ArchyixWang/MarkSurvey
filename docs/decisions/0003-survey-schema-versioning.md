# ADR-0003：问卷 Schema、版本与填写任务

- 状态：Accepted
- 日期：2026-10-20

## 背景

问卷题目、分页和跳转规则会持续演进，同时已经提交的答卷必须保持可解释。系统还需要一个稳定链接，让填写者在重新发布后继续访问同一份问卷。

## 决策

- 使用版本化 JSON Schema 描述完整问卷内容，题目和选项 ID 在版本间保持稳定。
- `surveys` 保存可编辑草稿与稳定短码，`survey_versions` 保存发布时不可变快照。
- `surveys.active_version_id` 是发布任务当前绑定的 TemplateVersion；重新发布只切换该指针。
- 标题、说明、匿名、重复填写、页面、题目和规则全部进入版本；截止时间和生命周期不进入版本。
- 草稿答案绑定创建时的版本；重新发布或关闭会作废开放草稿，后续进入绑定新版本。
- 匿名答卷在提交后删除用户 ID，保存服务端密钥派生的 HMAC 键以满足去重和去重人数统计。

## 后果

- 历史内容和答卷可审计，同一链接无需变化即可发布新版本。
- 编辑器需要维护稳定 ID、版本哈希和 revision 并发控制。
- 跨版本统计只能安全聚合当前 Schema 仍存在的题目与选项；删除的结构不再展示。
