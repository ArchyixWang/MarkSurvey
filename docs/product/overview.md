# MarkSurvey 产品概览

状态：多租户认证、问卷体系与工作台一期已实现
更新时间：2026-10-20

## 产品定位

MarkSurvey 是一个在线问卷系统。当前已完成端到端闭环：每个注册用户拥有独立工作空间，可通过密码或邮箱验证码安全登录，在问卷管理器中创建、编辑、发布问卷，并通过稳定链接邀请登录用户填写和查看统计。

## 已确认原则

- 采用规格驱动开发（SDD），需求先文档化，再进入 Goal 与实现。
- 工程明确区分前端、后端和文档。
- 重要的前后端设计与需求必须沉淀在 `docs/`。
- 前端使用 Vite，UI 规范使用 Ant Design。
- 后端使用 Python，数据库使用 MongoDB。
- 开发时关注跨组件、跨端联调，并保持高内聚、低耦合。
- 每完成一个小功能提交一次 commit。

## 已实现能力

- 注册时自动创建独立租户，注册者成为该租户的 `owner`。
- 用户名用于展示；账号和邮箱全局唯一，登录时大小写不敏感。
- 密码登录支持账号或邮箱；邮箱验证码登录只使用邮箱。
- 发送注册、邮箱登录和找回密码验证码前必须完成服务端滑块挑战。
- 找回密码成功后注销该用户全部现有会话。
- 工作台采用全宽顶栏和左侧功能栏，内容区提供工作台入口与已启用的问卷管理；窄屏侧栏折叠为抽屉。
- 会话刷新后可恢复，退出登录后受保护路由不可访问。
- 问卷支持标题、说明、匿名填写和重复填写设置；发布后生成稳定 `/survey/{short_code}` 链接。
- 问卷题目支持单选、多选、文本和数字四种类型，支持必答、选择数量、长度、范围与整数约束。
- 支持连续展示或自定义分页；单选、多选和数字答案可配置跳转规则，发布时拦截冲突。
- 支持不可变 TemplateVersion、历史版本查看、版本复制为草稿、截止时间与关闭后重新发布。
- 填写必须登录；答案 500ms 防抖自动保存，重新进入可恢复草稿，提交时只校验有效路径。
- 匿名提交删除用户关联并保留 HMAC 去重键；重复提交限制按当前用户与在线 Schema 生效。
- 统计聚合全部已提交答卷，按当前在线 Schema 展示答卷数、去重参与人数、选项分布、数字汇总和文本答案。

## 范围状态

| 范围项 | 状态 |
| --- | --- |
| 问卷创建、编辑与发布 | 一期已实现 |
| 答卷填写与提交 | 一期已实现 |
| 数据统计与分析 | 一期已实现 |
| 多租户注册、登录、找回密码与工作台壳层 | 一期已实现 |
| 邀请成员、角色管理、租户切换与租户设置 | 不在本期范围，待后续需求 |

本期租户采用单 owner 模型，不提供邀请、成员管理或租户切换。所有后续问卷业务数据必须归属于当前会话所在租户。

问卷一期不包含删除、成员协作、答案导出、附件题、评分题、公开免登录填写、通知和高级图表。重新发布复用同一短码，历史版本与已提交答卷永久保留。

未确认的功能不应提前写入实现或对外文案。

## 质量目标

- 规格可审阅：每项功能有明确边界、接口和验收条件。
- 契约可联调：前端与后端围绕版本化 API 契约协作。
- 模块可演进：业务逻辑按领域模块聚合，跨模块依赖保持显式且最小。
- 变更可追踪：文档、对话记录、变更记录和 Git 提交形成完整链路。
