# MarkSurvey 产品概览

状态：已确认基础信息
更新时间：2026-10-20

## 产品定位

MarkSurvey 是一个在线问卷系统。当前已确认产品名称与系统类型，具体用户角色、问卷能力、发布方式和数据分析范围尚未冻结。

## 已确认原则

- 采用规格驱动开发（SDD），需求先文档化，再进入 Goal 与实现。
- 工程明确区分前端、后端和文档。
- 重要的前后端设计与需求必须沉淀在 `docs/`。
- 前端使用 Vite，UI 规范使用 Ant Design。
- 后端使用 Python，数据库使用 MongoDB。
- 开发时关注跨组件、跨端联调，并保持高内聚、低耦合。
- 每完成一个小功能提交一次 commit。

## 质量目标

- 规格可审阅：每项功能有明确边界、接口和验收条件。
- 契约可联调：前端与后端围绕版本化 API 契约协作。
- 模块可演进：业务逻辑按领域模块聚合，跨模块依赖保持显式且最小。
- 变更可追踪：文档、对话记录、变更记录和 Git 提交形成完整链路。
