# 题库、题目版本与跨问卷统计二期规格

- 状态：Implemented
- 负责人：MarkSurvey
- 创建日期：2026-10-29
- 更新时间：2026-10-29
- 关联 Goal：题库、题目版本与跨问卷统计二期

## 1. 背景与目标

一期问卷题目只存在于问卷 Schema 中，无法跨问卷复用，也无法独立追踪题目版本和跨问卷回答趋势。本期新增独立题库领域，使题目内容成为可版本化资产，同时保证已发布问卷及历史答卷不被后续题目修改影响。

## 2. 范围

### 本期包含

- 个人题目库、题目根与不可变版本。
- 从题库选择版本插入问卷，以及把问卷现有题目保存到题库并关联。
- 登录后可访问的题目分享链接、可选有效期、撤销和独立复制。
- 共享区保存接收的分享及复制出的本地题目。
- 题目归档与恢复。
- 题目版本来源、恢复来源、派生题目来源和共享复制来源。
- 题目被哪些本人问卷使用，以及跨问卷、跨版本统计。

### 本期不包含

- 命名题库、团队或租户共享题库、多人共同编辑、逐用户授权。
- 题目硬删除、批量迁移、历史关联回填、答案导出和高级图表。
- 共享来源更新同步到接收方独立副本。

## 3. 核心模型

### 题目根

题目根保存所有者、租户、不可变题型、最新版本号、归档状态、派生来源和时间戳。题目根是选题、分享、使用记录和跨问卷统计的稳定身份。

### 题目版本

题目版本不可变，保存题干、说明、题型配置、选项、约束和默认必答值。题库版本不保存问卷内必答状态和跳转规则。版本号从 1 递增，创建时使用最新版本号做乐观并发控制。

- 普通修改创建新版本，并记录基础版本。
- 恢复旧版本会复制内容创建新版本，并记录恢复来源。
- 派生新题创建新题目根，可改变题型，并记录来源题目和版本。
- 共享复制创建接收方自有题目根 v1，并记录来源。

### 分享与共享区

- 分享作用于整个题目根，令牌只存哈希。
- 分享链接要求登录，可设置截止时间或长期有效，创建者可撤销。
- 接收方可查看来源题目及版本，并选择一个版本复制为自有题目根。
- 每次复制都创建独立、完全冻结的题目，不跟随来源更新。
- 共享区按复制记录展示来源分享和接收方本地题目。

### 使用记录

问卷发布时为每个仍处于关联状态的题库题目写入使用记录，内容包括题目根、题目版本、问卷、问卷版本、问卷题目实例和所有者。历史使用记录不因后续草稿解除关联、题库增加版本或归档而删除。

## 4. 问卷 Schema 扩展

问卷 Schema 保持 `schema_version = 1`，新增可选 `library_ref`：

```json
{
  "library_ref": {
    "question_id": "题目根 ID",
    "version_id": "题目版本 ID",
    "linked": true
  }
}
```

- 问卷题目实例 ID 仍由问卷生成，不使用题库题目或版本 ID 代替。
- 关联题目的内容必须与所引用题目版本一致，但问卷必答状态和跳转规则可以独立配置。
- 插入时默认必答值取自题库版本，之后作为问卷本地字段调整。
- 关联状态下题干、说明、选项和约束只读；直接修改内容会解除关联，并保留来源元数据用于追溯。
- 解除关联后的发布版本不写入新使用记录。
- 同一问卷版本最多关联同一个题目根一次。
- 归档题目不能新链接入问卷；已链接草稿仍可发布。
- 现有问卷不自动迁移，用户按题执行“保存到题库并关联”。

## 5. 统计规则

- 只统计当前用户创建的问卷，不向分享者暴露接收方私有副本、问卷或答卷。
- 合并题目根所有已使用题目版本的已提交答卷，包含关闭问卷和匿名答卷，排除草稿。
- 同一用户在不同问卷或不同版本中的答案分别计入，不跨问卷合并身份。
- 选择题按稳定选项 ID 合并；文案取最新或最后出现值，已删除选项继续以历史选项展示。
- 数字题展示答案数、平均值、最小值和最大值。
- 文本题展示可追溯来源问卷、问卷版本和提交时间的分页答案。
- 题目统计同时提供总体结果和逐题目版本结果。

## 6. API 契约

管理接口位于 `/api/v1/question-library`：

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| POST | `/questions` | 创建题目根与 v1 |
| GET | `/questions` | 分页列出当前用户题目，支持搜索、题型和归档筛选 |
| GET | `/questions/{id}` | 读取题目根、最新版本、版本数和来源 |
| POST | `/questions/{id}/versions` | 基于最新版本创建不可变新版本 |
| GET | `/questions/{id}/versions` | 列出版本历史 |
| GET | `/questions/{id}/versions/{version_id}` | 读取指定版本 |
| POST | `/questions/{id}/versions/{version_id}/restore` | 复制旧版本生成新版本 |
| POST | `/questions/{id}/versions/{version_id}/derive` | 派生新题目根 |
| POST | `/questions/{id}/archive` | 归档题目 |
| POST | `/questions/{id}/unarchive` | 恢复归档 |
| POST | `/questions/{id}/shares` | 创建登录访问分享链接 |
| GET | `/questions/{id}/shares` | 列出现有分享 |
| POST | `/questions/{id}/shares/{share_id}/revoke` | 撤销分享 |
| GET | `/shares/inbox` | 列出共享区复制记录 |
| GET | `/shared/{token}` | 登录用户读取分享来源和可复制版本 |
| POST | `/shared/{token}/imports` | 复制指定版本为接收方独立题目 |
| GET | `/questions/{id}/usage` | 列出本人使用该题目的问卷和版本 |
| GET | `/questions/{id}/statistics` | 返回总体与逐版本跨问卷统计 |
| GET | `/questions/{id}/statistics/text-values` | 分页读取文本答案 |

所有写接口要求会话和 CSRF。跨用户或跨租户管理资源返回 404。新增错误码：

- `QUESTION_LIBRARY_INVALID`
- `QUESTION_VERSION_CONFLICT`
- `QUESTION_SHARE_UNAVAILABLE`
- `QUESTION_ARCHIVED`
- `QUESTION_REFERENCE_INVALID`

## 7. 前端交互

- `/workspace/questions`：个人题目和共享区 Tabs、搜索、题型/状态筛选、分页表格和创建入口。
- `/workspace/questions/:id`：内容、版本历史、来源关系、分享管理、使用问卷、归档与恢复。
- `/workspace/questions/:id/statistics`：总体和逐版本统计、选项分布、数字指标和文本答案。
- `/shared/questions/:token`：受保护分享预览和复制入口，未登录时登录后安全回跳。
- 问卷编辑器提供题库选题 Drawer、切换版本、保存到题库、来源标签和解除关联操作。
- 全部页面继续遵循 Ant Design、固定工作台视口、内部滚动、Design Token 和 320px 响应式要求。
