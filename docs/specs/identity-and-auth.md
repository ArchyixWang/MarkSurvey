# 多租户身份、认证与工作台一期规格

- 状态：Implemented
- 负责人：MarkSurvey
- 创建日期：2026-10-20
- 关联 Goal：多租户身份、认证与工作台一期

## 1. 背景与目标

MarkSurvey 需要从工程骨架进入首个可用业务闭环：用户可以注册并创建自己的租户，通过密码或邮箱验证码登录，找回密码，并进入工作台。系统必须从第一版开始为用户、会话和后续业务数据建立租户隔离边界。

## 2. 范围

### 本期包含

- 注册、密码登录、邮箱验证码登录、退出登录、找回密码。
- 注册即创建租户，注册者成为租户 owner。
- 邮箱验证码发送与校验。
- 自建服务端拼图滑块验证。
- 自动登录、会话恢复与受保护路由。
- 全宽顶栏、左侧功能栏和空白工作台内容区。

### 本期不包含

- 邀请成员、成员管理、角色管理、租户切换、租户设置。
- 用户资料编辑、头像上传、第三方 OAuth、手机号认证。
- 问卷等具体工作台功能。

## 3. 用户流程

### 注册

1. 用户填写用户名、全局唯一账号、邮箱、密码、确认密码和邮箱验证码。
2. 点击发送验证码时先完成滑块验证，再请求注册验证码。
3. 提交注册后创建独立租户与 owner 用户，自动建立 24 小时会话并进入 `/workspace`。
4. 租户名称自动生成为 `{username}的工作空间`。

### 密码登录

1. 用户输入账号或邮箱、密码。
2. 点击登录时完成滑块验证。
3. 凭据、滑块令牌均有效时建立会话并进入 `/workspace`。

### 邮箱验证码登录

1. 用户输入邮箱并点击发送验证码，发送前完成滑块验证。
2. 输入收到的 6 位验证码后直接登录，不再进行第二次滑块验证。
3. 登录成功后进入 `/workspace`。

### 找回密码

1. 用户输入邮箱并发送验证码，发送前完成滑块验证。
2. 输入验证码、新密码和确认密码后重置密码。
3. 重置成功后注销该用户全部会话，返回 `/login`，不自动登录。

### 退出登录

工作台用户菜单提供退出操作。退出时删除服务端会话、清理 Cookie，并返回 `/login`。

## 5. 数据与权限

### 集合

- `tenants`：`_id`、`name`、`created_at`。
- `users`：`_id`、`tenant_id`、`username`、`account`、`email`、`password_hash`、`role`、`created_at`、`updated_at`。
- `sessions`：`_id`、`token_hash`、`csrf_token_hash`、`user_id`、`tenant_id`、`expires_at`、`created_at`。
- `email_codes`：`_id`、`email`、`purpose`、`code_hash`、`expires_at`、`attempts_remaining`、`consumed_at`、`created_at`。
- `captcha_challenges`：`_id`、`target_x`、`tolerance`、`attempts_remaining`、`verification_token_hash`、`verified_at`、`consumed_at`、`expires_at`、`created_at`。
- `rate_limits`：动作、作用域键、窗口起点、计数、过期时间。

### 约束

- `users.account` 与 `users.email` 使用规范化小写值建立全局唯一索引。
- 用户名只作为展示昵称，可重复，长度 2–32 字符。
- 账号为 4–32 位字母、数字或下划线，忽略大小写。
- 密码为 8–64 位，必须同时包含字母和数字，使用 Argon2id 哈希。
- 每个用户本期只属于一个租户，`role` 固定为 `owner`。
- 后续业务集合必须包含 `tenant_id`，仓储查询必须显式使用会话中的租户。
- 验证码、会话、滑块和限流记录均具有 TTL 或显式过期判断。

## 6. API 契约

### 公共响应与错误

成功建立会话时不返回会话令牌；令牌仅存在于 HttpOnly Cookie。`AuthSession`：

```json
{
  "user": {
    "id": "string",
    "username": "string",
    "account": "string",
    "email": "string",
    "role": "owner"
  },
  "tenant": {
    "id": "string",
    "name": "string"
  }
}
```

错误结构：

```json
{
  "error": {
    "code": "AUTH_INVALID_CREDENTIALS",
    "message": "账号或密码错误",
    "field_errors": {}
  }
}
```

### 接口

| 方法与路径 | 说明 |
| --- | --- |
| `POST /api/v1/auth/captcha-challenges` | 创建滑块挑战，返回背景图、拼图块和几何参数 |
| `POST /api/v1/auth/captcha-challenges/{id}/verify` | 提交偏移量，成功返回一次性 `captcha_token` |
| `POST /api/v1/auth/email-codes` | 发送注册、邮箱登录或密码重置验证码，要求滑块令牌 |
| `POST /api/v1/auth/register` | 注册并建立会话，返回 `201` |
| `POST /api/v1/auth/login/password` | 账号或邮箱密码登录，要求滑块令牌 |
| `POST /api/v1/auth/login/email` | 邮箱验证码登录 |
| `POST /api/v1/auth/password-reset` | 重置密码，返回 `204` |
| `GET /api/v1/auth/session` | 获取当前会话，未登录返回 `401` |
| `POST /api/v1/auth/logout` | 注销会话，要求 CSRF，返回 `204` |

### Cookie 与 CSRF

- `marksurvey_session`：HttpOnly、SameSite=Lax、Path=/、24 小时有效，生产环境 Secure。
- `marksurvey_csrf`：同寿命、可被前端读取的 CSRF Token。
- 已认证状态变更请求必须发送 `X-CSRF-Token`，后端同时校验 Cookie、请求头和会话中的 CSRF 哈希。
- 登录和注册成功时轮换新会话；密码重置清除该用户全部会话。

### 限流与验证码

- 验证码 6 位，10 分钟有效，60 秒重发冷却，按用途隔离，最多验证 5 次。
- 同一邮箱/用途每小时最多发送 5 次，同一 IP 每小时最多发送 20 次。
- 密码登录连续失败按账号/邮箱与 IP 维度限流，超过阈值返回 `429` 与 `Retry-After`。
- 验证码请求无论邮箱是否存在均返回相同成功语义，避免邮箱枚举。

## 7. 前端交互

- 公开路由：`/login`、`/register`、`/forgot-password`。
- 受保护路由：`/workspace`。
- `/` 根据会话跳转；未知路由回到 `/`。
- 登录页采用两个 Tab：密码登录、邮箱验证码登录。
- 注册页包含用户名、账号、邮箱、密码、确认密码、邮箱验证码。
- 所有验证码按钮具有 60 秒倒计时；服务端返回 `429` 时同步展示剩余时间。
- `SliderCaptcha` 为可复用控件，使用后端图片，失败自动复位；通过后将一次性 Token 交给调用方。
- 表单提交期间禁用重复操作，服务端字段错误回填至对应表单字段。
- 工作台顶栏横跨全宽，显示品牌、租户名称和用户菜单；侧栏仅展示工作台活动项及功能占位；内容区为空态。
- 窄屏下侧栏折叠为抽屉，顶栏仍保持可见。
- 所有界面使用中文和现有 Ant Design 主题 Token，不硬编码新的主色体系。

## 8. 异常与边界

- 验证码过期、错误、已达到尝试上限、用途不匹配和重复消费均拒绝。
- 滑块过期、位置错误、尝试耗尽和令牌重放均拒绝。
- 重复账号或邮箱返回 `409` 与字段错误。
- 账号不存在与密码错误使用同一登录错误，不泄露账号状态。
- SMTP 发送失败返回明确的服务失败状态，不回显验证码。
- 数据库不可用时应用启动失败并输出可诊断日志。

## 9. 验收标准

- [x] 新用户可完成滑块、邮箱验证码和注册，并自动进入独立租户工作台。
- [x] 同一账号或邮箱无法重复注册。
- [x] 用户可使用账号或邮箱 + 密码 + 滑块登录。
- [x] 用户可使用邮箱验证码登录，发码前需要滑块，最终登录无需第二次滑块。
- [x] 用户可通过邮箱验证码重置密码，既有会话全部失效。
- [x] 刷新工作台后会话可恢复，退出后受保护路由不可访问。
- [x] 工作台显示正确租户和用户信息，侧栏与内容区符合占位要求。
- [x] 后端、前端自动化测试与生产构建通过，真实 MongoDB 环境联调通过。
